## 1. Check your balance

Free, and the fastest way to confirm your key works.

<CodeGroup>
```bash cURL
curl https://api.pepo.ai/v1/credits \
  -H "Authorization: Bearer $PEPO_API_KEY"
```

```ts TypeScript
const res = await fetch('https://api.pepo.ai/v1/credits', {
  headers: { Authorization: `Bearer ${process.env.PEPO_API_KEY}` },
})
console.log(await res.json())
```

```python Python
import os, requests

r = requests.get(
    "https://api.pepo.ai/v1/credits",
    headers={"Authorization": f"Bearer {os.environ['PEPO_API_KEY']}"},
)
print(r.json())
```
</CodeGroup>

```json Response
{ "balance_usd": 20.0, "default_call_cap_usd": null, "mode": "live" }
```

## 2. Confirm your brand profile exists

Every workflow reads it. Without one you get category noise instead of answers about your brand, so the API refuses the call rather than returning something plausible and generic.

```bash
curl https://api.pepo.ai/v1/brand-profile \
  -H "Authorization: Bearer $PEPO_API_KEY"
```

A new workspace returns `200` with `"status": "needs_setup"` and the path to fix it — not an error. See [Brand profile](/brand-profile).

## 3. Price the call before you make it

Cost tracks how many candidate videos have to be analysed to find the results you asked for, which is not knowable in advance — so estimates come back as a band.

```bash
curl -X POST https://api.pepo.ai/v1/estimate \
  -H "Authorization: Bearer $PEPO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"endpoint":"/v1/trending","params":{"limit":25,"platforms":["tiktok"]}}'
```

```json Response
{
  "estimate": {
    "cost_usd": { "low": 3.02, "expected": 6.02, "high": 12.02 },
    "assumes": { "videos_returned": 25, "platforms": 1, "candidates_analyzed": 200 },
    "balance_usd": 20.0,
    "affordable": true
  }
}
```

`candidates_analyzed` is the number that surprises people: to return 25 good results the system looks at roughly 200, and you are billed against the candidates. It is in the estimate so it is never a surprise on an invoice.

## 4. Ask what is trending

```bash
curl -X POST https://api.pepo.ai/v1/trending \
  -H "Authorization: Bearer $PEPO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"platforms":["tiktok"],"window":"7d","limit":10,"max_cost_usd":5}'
```

`max_cost_usd` is a hard ceiling. Work stops there and returns partial results marked `usage.truncated` rather than overrunning it.

## 5. Read the result properly

This is the part worth slowing down for. A trimmed real response:

```json
{
  "results": [
    {
      "video": { "creator": { "handle": "@breakout" }, "url": "https://tiktok.com/…" },
      "metrics": { "views": 240000 },
      "momentum": {
        "score": 87,
        "classification": "trending",
        "confidence": "medium",
        "coverage": { "snapshots": 3, "hours_observed": 24 },
        "comparison_group": { "n": 27 },
        "floors_met": true,
        "gated_by": null
      }
    },
    {
      "video": { "creator": { "handle": "@thin" } },
      "metrics": { "views": 800000 },
      "momentum": {
        "score": 87,
        "classification": "watchlist",
        "confidence": "low",
        "coverage": { "snapshots": 2, "hours_observed": 3 },
        "floors_met": false,
        "gated_by": "Capped at watchlist: 2 snapshot(s) over 3h — \"trending\" requires at least 3 across 12h."
      }
    }
  ],
  "trend": {
    "verdict": "viral_video",
    "independent_creators": 1,
    "top_creator_share": 0.766,
    "reasons": ["A single video/creator dominates. One video outperforming is virality, not a trend."]
  },
  "caveat": null,
  "usage": { "cost_usd": 0.07, "balance_usd": 19.93 }
}
```

Three things to take from it:

<Steps>
  <Step title="The biggest number is not the answer">
    `@thin` has more than three times the views and is the one held at `watchlist`, because three hours of observation cannot show a trajectory. `gated_by` says so in words you can quote.
  </Step>
  <Step title="Check `floors_met` before you repeat a claim">
    It is the single field that says whether the evidence bar was cleared. `classification` plus `floors_met` is the honest summary; `score` on its own is not.
  </Step>
  <Step title="`trend` is a separate finding from `results`">
    Here five accelerating videos come from one creator holding 77% of the views, so the verdict is `viral_video`, not a trend. Ranking and movement are different questions.
  </Step>
</Steps>

<Warning>
If `caveat` is non-null, it is the most important field in the response. It says when the corpus cannot support the question you asked — no metric history yet, an empty corpus, or too little history to classify anything. Pass it on rather than summarising around it.
</Warning>
